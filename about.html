PROJECT OVERVIEW

About Cybersecurity Awareness Portal

Problem statement

Many users are exposed to phishing, weak passwords, unsafe public networks, malware, and social engineering because they lack practical cybersecurity awareness.

Proposed solution

CyberAware provides a centralized educational portal with awareness content, a knowledge quiz, a basic password-strength demonstration, and a sample incident-reporting workflow.

Technology stack

Python, Flask, HTML5, CSS3, JavaScript, and SQLite.

Scope and limitations

This mini project is an awareness and learning tool. It does not scan devices, detect live attacks, verify real URLs, or send reports to a real security operations team. The admin report page is intentionally a local demo and requires authentication before real deployment.
